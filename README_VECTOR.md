# EPV Vector Bridge — интеграция Google Фото через LSPosed/Vector

Это **отдельный Xposed APK-модуль**, не ZIP для KernelSU/Magisk. Он работает вместе
с [Encrypted Photo Vault](https://github.com/Mitchelded/Encrypted-Photo-Vault)
и **Vector Framework**.

## Что делает

- В приложении Google Фото появляется компактная панель **EPV | 18+ | Метки ✓** в правом нижнем углу.
- **Новый экспериментальный режим:** при прокрутке обычной сетки Google Фото модуль пытается определять откровенный контент на видимых миниатюрах и показывать прямо на плитках красную метку **18+ NN%**. Длительное сканирование всей библиотеки и скачивание оригиналов не требуются.
- **Метки ✓ / Метки —** — переключатель этих накладных подписей; состояние сохраняется в локальных настройках процесса Google Фото.
- **EPV** открывает основное приложение Encrypted Photo Vault с подсказкой,
  как выбрать шифрованные PNG из Google Фото через системный Photo Picker.
- **18+** открывает основное приложение и его локальный сканер.
  Для запуска нужна доступная на телефоне папка, пароль и порог. Текущий
  список проверенных файлов и возможность «Продолжить» хранятся в основном EPV.
- Без Xposed обычное Android «Поделиться» → **Encrypted Photo Vault** тоже
  позволяет передать выбранные Google Фото изображения или видео в EPV
  (требуется подтверждение шифрования и пароль). Для выбранных через
  «Поделиться» файлов есть также кнопка **«Проверить 18+ и зашифровать
  совпадения»** — локальная TFLite-модель оценивает фото или несколько кадров
  видео и шифрует только превышающие порог. Автоматическое удаление оригиналов
  не выполняется.
- Никаких изменений APK Google Фото, подмены Pixel и обхода проверок Google.

## Как работают метки на миниатюрах (Vector 0.2)

- За основу взята публично документированная точка встраивания `com.google.android.apps.photos.photoadapteritem.PhotoCellView.draw(Canvas)`, известная по [GooglePhotosMod](https://github.com/pbzin/GooglePhotosMod). Для Google Фото 7.87.x эта точка проверялась автором другого модуля, но на остальных версиях может отсутствовать.
- Модуль использует `PixelCopy` для получения уменьшенного изображения **видимой** плитки с экрана (160×160). Это не прямое чтение исходного фото или альбома. Только текущие видимые элементы.
- TensorFlow Lite MobileNetV2 `drawings/hentai/neutral/porn/sexy` запускается **локально в процессе Google Фото**, на отдельном потоке и с ограничением очереди. Порог `hentai + porn + sexy` ≥ 70%; плашка показывает вероятность модели, а не подтверждённую категорию.
- Для недавних результатов предусмотрен ограниченный оперативный кэш, новые запросы к видимым плиткам выполняются с интервалом. **Изображения, скриншоты и оценки не сохраняются в файлы и не отправляются на сервер**. Модель (~17 МБ) встроена в APK.
- **Это визуальная эвристика.** Кадрирование, цветокоррекция, текст и наложения интерфейса влияют на оценки. Возможны как ложные 18+ метки, так и пропуски. На видео анализируется **обложка** (а не видеопоток). Модель не определяет возраст людей.
- Если Google Фото в конкретной версии не использует `PhotoCellView`, метки в сетке не появятся, но кнопки быстрого доступа останутся. При несовместимости нативного TFLite модель отключится без намеренного изменения Google Фото.
- При обновлении изображений у переработанной плитки возможна кратковременная устаревшая плашка до следующего захвата. Для отключения нажми **«Метки ✓»**, затем **«Метки —»**; перезапуск Google Фото сохранит выбор.
- На очень большой галерее это дополнительная нагрузка ЦП/ОЗУ. Если скроллинг замедлился, выключи метки.

## Перенос 18+ без шифрования

**Удерживай кнопку «18+»** в панели Vector внутри Google Фото: откроется новая функция EPV **«18+ → отдельная папка (без шифрования)»**. Она сортирует **локальные** фотографии и видео в выбранную папку, не превращая их в PNG и не шифруя. Короткое нажатие 18+ по-прежнему открывает прежний режим.

Перед переносом пользователь вручную выбирает обе папки и подтверждает удаление исходников после копирования и сверки SHA-256. Прогресс можно остановить и продолжить. **Это не организация всей облачной библиотеки Google Фото** — её сторонним приложениям недоступно массово перемещать по API.

## Установка

1. Установи **Encrypted Photo Vault** (основной Android APK) из workflow
   [Android debug APK](https://github.com/Mitchelded/Encrypted-Photo-Vault/actions/workflows/android.yml).
2. Установи APK `EPV-Vector-Bridge-debug-apk` из workflow
   [EPV Vector LSPosed module APK](https://github.com/Mitchelded/Encrypted-Photo-Vault/actions/workflows/vector-bridge.yml).
3. Открой установленный Vector/LSPosed Manager и включи **EPV Vector Bridge**.
4. В **Scope/Область действия** поставь **только Google Фото**
   (`com.google.android.apps.photos`). Не выбирай System Framework,
   system_server, SystemUI и все приложения.
5. Принудительно останови Google Фото и запусти его снова.
6. Кнопки должны появиться внизу справа. На плитках с высокой оценкой 18+ появятся красные плашки **18+ NN%** после локальной проверки. Переключить отображение можно кнопкой **Метки ✓/—**.

Если EPV не установлен, модуль выводит уведомление о необходимости установки.

## Ограничения Google Фото

- Модуль **не получает полный список облачной библиотеки Google Фото** и
  **не читает внутренние токены** Google, не открывает закрытые API.
- Для облачных изображений доступен только системный выбор пользовательских
  файлов (Android Photo Picker), обычно с ограничением до 100 PNG за раз.
- Переданное через «Поделиться» медиа может быть временной/преобразованной
  копией, а не точным исходником. Для контейнеров EPV1 важно использовать
  оригинальные PNG-пиксели и все части.
- Для файлов, полученных через «Поделиться», 18+ классификация выполняется **внутри EPV**.
  Для экранных меток классификация выполняется **внутри процесса Google Фото** по временным
  уменьшенным скриншотам отображаемых миниатюр. Облачные файлы полностью не скачиваются.
  Необработанные или невидимые медиа не классифицируются.
- Плавающая панель вводится через стандартный lifecycle hook Activity.onResume,
  поэтому может визуально пересекаться с элементами новых версий Google Фото.
  Если мешает, выключи модуль для Google Фото в Vector.
- Изменения Google Фото или Vector могут нарушить hook. Для плашек используется
  один специфичный (хотя и не обфусцированный) класс Google Фото `PhotoCellView`,
  поэтому конкретную версию Google Фото необходимо проверить на устройстве.
- Потребляется **права процесса Google Фото**, не root. Сам EPV не получает root
  и ничего не читает из закрытого хранилища Google Фото.

## Совместимость

Проверяемая базовая платформа: Android 17, Xposed legacy API 82 под Vector.
Vector публично заявляет поддержку Android 8.1–17 Beta, но работа на
конкретной сборке OriginOS/Vector зависит от версии Zygisk и возможности
перезапустить нужный процесс. APK строится Gradle из `android/vector-bridge`,
платформа Xposed предоставляет `de.robv.android.xposed.*` в runtime.

Для возврата изменений достаточно выключить **EPV Vector Bridge** в Vector
и принудительно перезапустить Google Фото. Системные разделы не изменяются.
