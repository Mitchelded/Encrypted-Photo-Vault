# EPV: проверка 18+ на компьютере по USB

Телефон хранит фото и видео, а ПК получает **только уменьшенные JPEG-превью в оперативную память**. Никаких файлов с оригиналами на диск компьютера не записывается. Полностью без передачи пикселей с телефона на ПК анализ технически невозможен.

## Запуск на Windows 11

Установите 64-битный Python 3.12 и Android Platform Tools (adb). На первый запуск требуется интернет для установки библиотек и загрузки модели GantMan nsfw_model, затем сервер работает офлайн.

Из корня репозитория в PowerShell:

~~~powershell
py -3.12 -m venv .venv-epv
.\.venv-epv\Scripts\python.exe -m pip install -r pc_nsfw\requirements.txt
adb devices
adb reverse tcp:8765 tcp:8765
.\.venv-epv\Scripts\python.exe pc_nsfw\epv_server.py --workers 6
~~~

Можно использовать скрипт `pc_nsfw/start_windows.ps1`. Он выводит список устройств ADB, открывает USB-порт и запускает сервер.

Скопируйте код `Code for phone` из окна ПК. На телефоне: EPV → «18+ → отдельная папка» → включить «Анализ на ПК (USB/ADB)» → ввести код → «Проверить ПК», затем выбрать две папки и запустить перенос. Приостановка/продолжение работает как в обычном режиме.

## Параметры

- `--workers 6`: количество независимых ML-потоков на CPU (1–8). Для Ryzen 5 8400F 4 — разумное начало.
- `--port 8765`: порт; телефон использует только `127.0.0.1:8765`.
- `--token YOUR_TOKEN`: постоянный токен длиной от 12 символов вместо случайного кода.
- `--model FILE`: файл модели, SHA-256 которого должен соответствовать строго `380f98f7685f9d8a386f8cc595b6dfcb972989aae3d1b8b270d3a4a5b96fab40`.

## Безопасность и особенности

Сервер слушает только `127.0.0.1` компьютера. ADB reverse туннелирует локальный порт телефона на локальный порт компьютера. Токен проверяется на каждое обращение. Сервер не сохраняет полученные изображения и не печатает их имена в логах. Сама ML-модель (~17 МБ) скачивается на компьютер один раз.

Телефон декодирует и уменьшает кадры до JPEG-превью; нейросеть выполняется на ПК. Движок формирует пакеты по 8–16 файлов и использует несколько потоков обработки на компьютере. Для видео передаются максимум три кадра. В случае обрыва USB, неверного токена или недоступного сервера анализ останавливается; очередь прогресса остаётся на Android.

Оригиналы переносит только Android через SAF, после копирования и сверки SHA-256. Полная облачная библиотека Google Фото по-прежнему недоступна для массового сканирования.
