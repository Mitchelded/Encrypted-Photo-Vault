# Encrypted Photo Vault — EPV1

Рабочая **Windows/Python-утилита** и **исходный Android-проект** для хранения произвольных файлов в Google Фото в виде зашифрованных PNG с цветным шумом.

**Состояние проекта:** Python-часть испытана автоматическими тестами. Криптографическое ядро Java/Android (`EpvCore.java`) проверено на совместимость с Python в обе стороны. Android APK здесь **не собирался и на устройстве не испытывался**; проект содержит GitHub Actions для сборки APK.

## Windows

1. Установить [Python 3](https://www.python.org/downloads/) с `py` launcher.
2. Распаковать архив в удобное место.
3. Дважды щёлкнуть `Start-EPV-Windows.bat` — установятся библиотеки и откроется графическое окно.
4. Ввести пароль. Выбрать исходные фотографии/видео или папку. Указать выходную папку для PNG.
5. Передать созданные PNG на **Pixel XL первого поколения** (USB, Syncthing, локальная сеть и т. п.), разместить в папке картинок и включить её резервное копирование в Google Фото. Использовать **исходное качество**.
6. Для восстановления скачать все PNG файла, указать папку и правильный пароль в программе.

Альтернативно, из PowerShell в папке проекта:

```powershell
py -m pip install -r requirements.txt
py -m epv encrypt "C:\Users\You\Pictures" -o "C:\EPV_PNG"
py -m epv inspect "C:\EPV_PNG"
py -m epv restore "C:\EPV_PNG" -o "C:\Recovered"
```

Чтобы проверить **сохранность пикселей после Google Фото**:

```powershell
py -m epv cloudcheck "C:\EPV_PNG" "C:\Downloaded_From_Google_Photos"
```

Здесь сравниваются именно RGB-байты, а не метаданные PNG.

## Android

Проект Android Studio расположен в `android/`. Это приложение без root и без доступа к интернету:

- **Шифрование** выбранных файлов, сохранение PNG в `Pictures/EncryptedPhotoVault` (MediaStore).
- **Восстановление** скачанных PNG в `Download/EncryptedPhotoVault` (открытые оригиналы).
- **Приватная галерея:** расшифровка фотографий в памяти и чтение видео по частям через `MediaDataSource`, без экспорта открытого видео.
- Для выбора файлов/папок используется системный Android-проводник.

**Собрать APK:** загрузить содержимое архива в собственный GitHub-репозиторий → вкладка Actions → `Android debug APK` → Run workflow → скачать артефакт `EncryptedPhotoVault-debug-apk`. Либо открыть папку `android/` в Android Studio и собрать `assembleDebug`.

Совместимость: Android 10+; исходники Kotlin/Java, AGP 8.13.2, Kotlin 2.3.0.

## Технические свойства

- AES-256-GCM + Argon2id (64 MiB, 3 прохода). Каждый файл получает случайные соль и идентификатор; каждая часть — независимый случайный nonce.
- Данные и исходные имена/типы/размеры/хеши находятся внутри зашифрованной части, а не в PNG-метаданных.
- До 8 МиБ исходного файла на один PNG, размер картинки до 2048×2048.
- Для восстановления не требуется отдельный манифест. Части группируются по внутреннему ID, независимо от их имён и порядка.
- Неверный пароль и изменения пикселей детектируются проверкой аутентичности; восстановленный файл проверяется также по размеру и SHA-256.
- Скрыть количество PNG и примерный суммарный размер невозможно.

## Важно

**Не удаляйте оригиналы**, пока не протестировали полный путь *шифрование → загрузка с Pixel XL → скачивание → cloudcheck → восстановление*. Возможность безлимитного исходного качества на оригинальном Pixel официально предусмотрена Google, однако сохранность всех пикселей после фактического экспорта необходимо испытать отдельно. Если пароль потерян, восстановить файлы нельзя. Код пока не проходил независимый аудит, не используйте проект как единственный архив важных данных.

`sample/` содержит пример с известным паролем `example-password-not-for-real-data` и инструкцией, как испытать Google Фото. Этот пароль нельзя использовать для настоящих секретов.
